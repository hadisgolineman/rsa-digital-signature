
# RSA Digital Signature Project

A Python project that implements digital signatures using RSA and SHA-256.

## About the Project

This project demonstrates how digital signatures work using asymmetric cryptography.

It allows users to:
- Generate RSA public and private keys.
- Protect the private key with a password.
- Sign files using RSA-PSS.
- Verify digital signatures.
- Detect file modifications.

## Technologies Used

- Python
- RSA
- SHA-256
- RSA-PSS
- Cryptography Library

## Installation

Install the required library:

```bash
pip install cryptography
```

## How to Run

Run the following command:

```bash
python rsa_digital_signature.py
```

## Security Features

- Password-protected private key.
- RSA 2048-bit key generation.
- SHA-256 hashing.
- RSA-PSS digital signatures.
- File integrity verification.
